## 功能概览
- 深色星际控制台风格响应式 UI
- Agent 对话工作区
- 角色设定与资源管理
- 模型及 TTS/ASR 服务状态
- 固定类型自动任务、任务记录与人工审批
- 原生桌宠文字模式修订说明

## 安全提醒
默认仅在本机回环地址运行。不要提交 API Key、`.env`、数据库、日志、模型权重、私人音频或个人配置。修改源码前先备份，代码补丁应人工审核。
