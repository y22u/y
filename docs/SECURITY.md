# 安全、隐私与发布检查

## 不应提交到 GitHub
- `.env`、API Key、访问令牌、密码、私钥和 Cookie。
- 本地数据库、聊天历史、用户配置。
- 运行日志、调试转储和崩溃报告。
- 虚拟环境、缓存、构建临时目录。
- 模型权重、下载缓存、私人参考音频和语音样本。
- 未经授权的角色图片、语音或其他第三方素材。

若密钥曾提交到公开仓库，应立即撤销或轮换密钥。只从最新版本删除文件不能使历史提交中的密钥失效。

## 自动任务边界
- 仅允许固定任务类型，不暴露任意 Shell、PowerShell 或 Python 执行接口。
- 限制代码补丁的相对路径、允许扩展名和内容大小。
- 修改前备份；写入前需要人工明确批准。
- 进程重启后不自动重放可能有副作用的任务。
- 发布打包时排除数据库、日志、凭据、模型、私人音频和个人配置。

## 本机服务
默认仅绑定 `127.0.0.1`。不要直接改成 `0.0.0.0` 或通过路由器端口转发暴露服务。远程访问需要先设计身份验证、TLS、访问控制、速率限制与审计。

## 许可证
分别核对项目 LICENSE、依赖、模型权重、角色素材和参考音频的许可条件。代码许可证不自动授予模型或角色素材的再分发权。
