# 故障排查

## 网页无法打开
1. 确认 `start_service.bat` 的命令行窗口仍在运行，查看最后 10–20 行错误。
2. 在 CMD 执行 `netstat -ano | findstr :8765`，确认端口是否被监听。
3. 执行 `curl -v --max-time 5 http://127.0.0.1:8765/` 检查 HTTP 响应。
4. 若出现 `Address already in use`，先识别占用进程，不要结束不认识的进程。

## 常见错误
- **No module named ...**：确认当前 Python/Conda 环境，并按项目要求运行安装脚本。
- **连接被拒绝**：服务可能未启动，或实际端口与预期不同。
- **窗口闪退**：从已打开的 CMD 进入项目目录再运行启动脚本，以保留错误输出。
- **仍是旧 UI**：确认启动的是新版目录，关闭旧进程后重新启动并刷新浏览器。

## Agent 无回复
检查本地服务是否运行、模型提供方配置、Ollama 或其他后端是否可访问，以及服务日志和浏览器请求状态。不要把密钥粘贴到公开 Issue。

## TTS/ASR 不可用
检查服务进程、模型文件、依赖、硬件资源和端口；检查系统音频输入/输出设备与权限。健康检查通过不保证实际语音生成成功，应进行试听。

## 自动任务失败
查看任务状态、事件和日志。不要自动重放有副作用的任务。代码补丁需重新核对路径和内容并走人工审批。质量门禁失败时先检查报告，不要直接发布。

## 安全提醒
不要将本机服务直接暴露到公网。不要通过删除数据库、模型或角色目录来解决普通启动问题；先备份并定位原因。
