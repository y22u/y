# Windows 安装与启动指南

> 注意：当前仓库已发布项目介绍和文档，但尚未包含完整应用源码。请先取得完整的 StarPetFusion 4.10.26 发布包。

## 安装前
- 确认 Windows 与项目要求的 Python 版本。
- 如果使用 Conda，先确认终端激活的是预期环境。
- 备份旧项目目录，将新版本解压到独立文件夹。
- 不要覆盖唯一的旧版本，也不要删除旧的角色数据或数据库来尝试修复问题。

## 安装与启动
1. 在项目根目录运行 `setup.bat`，等待依赖安装完成。
2. 双击 `start_service.bat`，保持命令行窗口开启。
3. 按当前部署说明在浏览器打开 `http://127.0.0.1:8765/`。
4. 先检查服务状态，再检查模型连接。
5. 逐项测试 Agent 对话、角色库以及需要使用的 TTS/ASR 服务。

如果安装脚本失败，保留完整错误输出。只有在项目确实提供该依赖清单时，才手动运行 `python -m pip install -r requirements-service.txt`，并确认使用正确的 Python 环境。

## 安全建议
默认仅在本机回环地址运行。不要未经审查改成监听 `0.0.0.0` 或向公网开放端口。修改前先备份；不要将密钥、日志、数据库、模型或私人音频上传到公开仓库。

## 回滚
停止服务后，将当前版本目录移出工作目录，再恢复此前备份。保留故障现场和日志副本，以便排查。
